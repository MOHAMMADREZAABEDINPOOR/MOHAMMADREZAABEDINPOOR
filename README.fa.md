# محمدرضا عابدین‌پور

سازنده مجموعه **PIMX**؛ پروژه‌های من از ابزارهای هوش مصنوعی و وب تا برنامه دسکتاپ، ربات تلگرام و تجربه‌های سه‌بعدی گسترده‌اند. این صفحه راه ورود به مخزن‌های من است؛ هر پروژه راهنمای مستقل انگلیسی و فارسی دارد.

## چیزی که می‌سازم

- فضاهای کاری هوش مصنوعی برای گفتگو، پژوهش و خروجی قابل استفاده.
- ابزار کاربردی تبدیل فایل، اصلاح چیدمان کیبورد و کار در مرورگر.
- تجربه دیداری برای کاوش ماهواره، آب‌وهوا و پروژه مستقل.
